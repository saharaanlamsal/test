# Exam Logo Slots

Each exam card now has an empty logo slot. Drop an image file here using the
exact filename below and it'll appear automatically — no code changes needed.

| Exam                     | Filename                     |
|---------------------------|-------------------------------|
| IELTS                      | ielts.png                    |
| UKVI IELTS                 | ukvi-ielts.png               |
| PTE Academic                | pte-academic.png             |
| TOEFL iBT                   | toefl-ibt.png                |
| Duolingo English Test        | duolingo-english-test.png    |
| SAT                          | sat.png                      |
| GRE                          | gre.png                      |
| GMAT                         | gmat.png                     |
| OET                          | oet.png                      |
| NCLEX                        | nclex.png                    |
| Prometric                    | prometric.png                |

**Format tips:**
- PNG with a transparent background works best (the slot has a light gray
  backdrop, so a white square logo will look boxed-in).
- Roughly square or logo-lockup shaped images fit the slot best. It auto-scales
  to fit (`object-fit: contain`), so exact pixel size doesn't matter much —
  anything from 200×200 to 600×200 works fine.
- Until you add a file, the slot shows a plain gray box with the exam's first
  letter — that's expected, not a bug.

**One thing worth keeping in mind:** these are other companies' trademarks
(ETS, Pearson, British Council/IDP, GMAC, College Board, Duolingo, etc.).
Using their logos to advertise your voucher/booking service is common
practice among resellers, but it's still their IP — if you ever get a
takedown request or want to be extra safe, swapping a logo out for the
colored text-badge style is a quick fix (just point the `<img>` `src` at
nothing or remove the tag).
